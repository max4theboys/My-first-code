# Arcade website

A small static arcade site with Snake, Minesweeper, a climbing game, and Pac-Man.

Run locally:

```bash
python3 -m http.server 8080 --directory .
```

Then open http://localhost:8080 in a browser.

GitHub Pages deployment is configured to publish the site at:
https://max4theboys.github.io/My-first-code/

Share an idea using the [arcade feedback form](https://max4theboys.github.io/My-first-code/#emailSection).
The form asks for your Gmail address and what you would like changed or added.
Submissions are sent through FormSubmit to `max4theboysyt@gmail.com`.
The recipient must activate FormSubmit using the confirmation email sent after the
first submission; submissions can be delivered after activation.
